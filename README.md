# 🏪 Manju Kirana Store - Jatkhedi, Bhopal

A lightweight, mobile-responsive local grocery store website built entirely with **pure HTML5 and CSS3** (zero JavaScript). Designed for local customers in Jatkhedi and Shri Rameshwaram, Bhopal to browse daily essentials and place instant orders via WhatsApp.

## ✨ Key Features
- **Pure HTML & CSS:** Fast-loading multi-page layout (`Home`, `Products`, `About Us`, `Contact`) with smooth zoom-in hover animations.
- **Direct WhatsApp Ordering:** Pre-filled click-to-chat links (`wa.me`) for individual products as well as a custom grocery list form.
- **Mobile-First Responsive Design:** Built using CSS Grid and Flexbox to work smoothly on smartphones and desktops.
- **Local Store Details:** Includes store timings, Jatkhedi address, and direct Google Maps directions.

## 🛠️ Tech Stack
- **HTML5** (Semantic structure & forms)
- **CSS3** (CSS Grid, Flexbox, Keyframe animations)
